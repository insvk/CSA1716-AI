# ParkFlow Realtime Smart Parking Dashboard

Premium responsive dashboard starter for ESP32 + 8 parking slots.

Start with `SETUP_GUIDE.md`. This package includes the dashboard, Supabase schema, Vercel ingestion API and ESP32/Wokwi integration helper. It does not include your existing firmware or a trained ML model. Configure your own keys, connect the firmware and verify the full path before calling it live.
